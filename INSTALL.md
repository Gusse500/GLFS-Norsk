# Install

Nå som du har lastet ned kildekodene, vil du sannsynligvis konvertere XML 
filene til HTML. For å gjøre det trenger du følgende pakker:
- libxml2
- libxslt
- docbook-xsl-nons
- docbook-4.5-dtd
- tidy

Installasjonsinstruksjoner for alle disse pakkene er tilgjengelige på
[BLFS bok](https://lfs.freding.no/blfs/index.html).
